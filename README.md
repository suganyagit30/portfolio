# Suganya R – Portfolio (React + Vite)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

## Replace the placeholders (all in `src/data.js`)
- email, LinkedIn, GitHub URLs
- project `demo` and `repo` links (buttons are disabled until filled in)
- put your photo at `public/profile.jpg` and resume at `public/Suganya_R_Resume.pdf`
- replace the project thumbnails in `src/components/Projects.jsx` with real screenshots

## Contact form
Create a form at Formspree (or similar), copy `.env.example` to `.env`, and set `VITE_FORM_ENDPOINT`.
